# 기업 성장성 직접 제공값 활용
사용자 승인에 따라 네이버/KRX/KIS 제공 성장률은 독립 교차검증 없이 사용한다. 기존 20점(매출 증가율5, 영업이익 증가율7, 순이익 증가율5, 매출 CAGR3) 유지. 먼저 한국투자증권 공식 financial-ratio FHKST66430300과 income-statement FHKST66430200을 사용하여 실제 연간 값, ROE, 부채비율도 같은 호출로 확보. CAGR은 2022~2025년 네 개 연도 매출의 3구간 기준. 과거 후보의 3개년도/2구간은 새 3년 CAGR에 혼입 금지. 수치 재검증을 생략하지만 회계기간/실적·예상/출처를 기록하고 흑자전환과 적자확대의 단순 성장률 해석 및 직접 제공값과 기존 대칭 성장률의 혼용은 방지한다. 이번 작업은 수집/결측 보완 가능성 진단이며 통합점수는 후속 단계. 과거 동결 스냅샷에 현재 자료를 소급 반영하지 않는다. 네이버/KRX 누락 보완 미구현.
