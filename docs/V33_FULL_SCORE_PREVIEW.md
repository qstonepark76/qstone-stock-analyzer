# 전체 평가점수 증거 통합
사용자 요청에 따라 백테스트 확대와 UI 작업보다 전체 평가점수 통합 우선. 290개 대상 각각 확정 배점에 따라 종합평가, 상승 선행지수, 60:40 복합평가의 산출/결측 슬롯을 하나의 파일로 묶는다. 동결 기준일 점수와 신규 후보 소스 획득일이 달라 혼합 자료는 진단용 부분합 및 가중 충족률만 산출. 최종 점수/순위 없음. 총순이익을 지배주주순이익으로 대체하지 않으며, 업종 대분류 진단 점수 및 1개월 추이를 정확한 30일 신호로 사용하지 않음. 3개 이상 증권사 목표가 30일 비교는 기업행위 범위 확인 전 후보. 출처 및 제한을 슬롯별 보존. 동일 기준일 원천 및 미산출 세부항목 해결 후 최종 점수 확정. 구버전/운영 파일/배포 변경 없음.
