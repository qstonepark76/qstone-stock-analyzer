# 리포트 이익 전망 변경률 직접 산출 및 점수
기존 2점 배점 유지, 외부 리포트 수치 교차검증 없음. 동일 기업·동일 증권사·동일 회계연도·동일 순이익 계정·동일 단위/연결범위의 추정값을 비교. 리포트에서 해당 연도 순이익 추정치 상향·하향률을 직접 제공하면 우선 사용. 지배주주 순이익과 총순이익 혼합 금지, 전년 성장률을 전망 변경률로 오인 금지. 3개 이상 독립 증권사 평균 신뢰계수 1, 1~2개 0.9(보수적 단일 출처 계수); 기존 2점 산식 사용. 양의 기존 이익과 비음수 변경 이익이면 통상 변화율, 손실 전환/축소는 대칭 변화율. 원문 주소와 페이지 및 사용 수치 보존. 자체 추정모델만 예측 성과 검증 유지. 이 구현은 최대 60건 리포트 원문 접근·추출 시험 및 현재 후보 점수이며 전수 추출 또는 운영 통합 완료가 아니다. 30일 상승선행지수로 소급 대체하지 않음.
