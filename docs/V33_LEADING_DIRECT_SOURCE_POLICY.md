# 사용자 승인: 상승 선행지수 직접 원천 활용
네이버 증권, 한국거래소(KRX), 한국투자증권(KIS)에서 제공한 실제 자료는 다른 공급자와 수치가 일치하는지 별도 교차검증하지 않고 사용한다. 기존 KIS 수급 거래량과 KRX 거래량 대조 및 KIS 수정 종가와 KRX 종가 대조는 신규 직접 수집 모드에서 생략. 원래 수정주가 API 설정, 동일 종목/거래일/기간/단위, 출처 및 결측 확인은 유지. 목표가도 같은 공급자 자료의 실제 발표값을 그대로 활용하며 기업행위 조정 여부를 임의로 가정하지 않고 원천 표기 유지. 30일 전후 동일 증권사 자료와 기존 최소 3개사 기준 유지(한두 증권사 자료는 별도 후보). 업종 수익률 및 실적 자료가 직접 제공되는 경우에도 동일 정의와 기간만 확인하고 교차검증은 불필요. 배점, 60:40 비율, 종합 97%/선행 95% 목표 불변. 과거 동결 결과와 운영 버전 변경 없음. 직접 원천 시험은 현재 날짜 자료부터 별도 산출하고 이전 날짜 자료와 섞어 공식 순위로 발표하지 않는다.
