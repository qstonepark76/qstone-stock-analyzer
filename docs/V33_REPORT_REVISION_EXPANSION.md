# 리포트 이익 전망 변경률 확대
59건 원문 확보, 12개 리포트에서 34개 수치 추출, 2개 기업 후보 점수 산출(기존 시험). 최대 150개 신규 상세 요청으로 확대하며 기존 추출 성공값 재사용. 최대 3개 증권사별 서로 다른 날짜의 최근 2건을 우선, 명시적 상향/하향/유지 표현 추가, 단위 환산(백만원/억원/십억원/조원) 지원. 실제 최신 리포트 날짜의 추정치가 없는 경우 이전 추출치를 최신으로 간주하지 않음. 외부 교차검증 없음. 신규 실행 전 충족률 개선 단정하지 않음. 원문 저장 없음. 구 시험의 중복 자동 실행 차단.
