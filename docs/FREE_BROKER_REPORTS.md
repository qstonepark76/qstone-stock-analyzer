# 무료 공개 증권사 리포트 컨센서스 운영 안내

## 데이터 원칙
- 무료로 공개된 증권사 리서치 자료만 사용합니다.
- 리포트 PDF 원문을 저장하거나 웹사이트에 재배포하지 않습니다. 리포트 제목/발행사/발행일/투자의견/목표주가 등 검증된 메타데이터와 원문 링크만 기록합니다.
- PDF나 페이지에 명시되지 않은 수치는 추정하거나 AI로 보완하지 않습니다.
- 최근 90일 이내 자료를 컨센서스 산출 대상으로 사용합니다.
- 동일 증권사의 중복 리포트는 최신 1건만 반영합니다.
- 최소 3개 증권사 의견이 확보된 종목만 컨센서스 점수 산출 대상입니다.

## 1차 무료 검색 경로
1. [한경 컨센서스](https://markets.hankyung.com/consensus/) — 여러 증권사의 공개 기업분석 리포트 검색 및 종목별 목표주가·투자의견 확인. Q Stone Park에서는 외부 링크로 연결하며, 자동 수집·저장하지 않습니다.
2. [네이버페이 증권 리서치](https://finance.naver.com/research/) — 종목·산업 리포트 검색
3. 각 증권사 공식 리서치센터 — 원문 및 발행 정보 재확인

포털은 발견·검색 경로로 사용하고, 원문 링크와 수치의 근거는 발행 증권사의 공식 자료를 우선합니다. 한경 컨센서스는 화면에서 공개되는 리포트 제목·목표주가·작성자·발행기관·발표일 및 검색 필터를 이용자가 직접 확인하도록 연결합니다. Q Stone Park가 한경 페이지를 크롤링하거나 본문·PDF를 복제하지 않습니다. 공개 열람이 가능하더라도 자동 수집·저장·재배포 권한이 자동으로 부여되는 것은 아니므로, 각 서비스 약관과 저작권 조건을 준수합니다.

## 데이터 입력
`data/analyst_reports.json`의 `reports` 배열에 다음 필드를 기록합니다.

- `ticker`: 6자리 종목코드
- `company`: 종목명
- `broker`: 발행 증권사명
- `analyst`: 애널리스트명(확인되는 경우)
- `published_at`: 발행일 YYYY-MM-DD
- `rating`: 보고서에 명시된 투자의견(예: 매수, 중립, 보유, 매도)
- `target_price`: 목표주가(숫자)
- `previous_target_price`: 직전 목표주가(보고서에 명시된 경우만)
- `title`: 리포트 제목
- `source_url`: 공개 원문 또는 공식 상세 페이지 URL

## 점수 산식 (컨센서스 10점 영역)
- 투자의견 점수 50%: 매수/중립/매도 등 명시된 의견을 내부 공통 척도로 변환
- 목표주가 상승여력 30%: 현재가 대비 평균 목표주가 괴리율의 종목 간 백분위
- 목표주가 변경률 20%: 직전 목표주가 대비 변경률의 종목 간 백분위
- 각 하위 데이터가 없으면 해당 비중은 결측 처리합니다. 커버리지는 실제 확보된 하위 비중만큼만 인정합니다.
- 종합 공식 추천은 기존 7개 평가영역이 모두 실제 확보되어야 합니다. 리포트가 부족하면 잠정 평가에만 반영합니다.

## 대시보드 표시
- 종목 상세에 최근 90일 리포트 중 최신 5건의 발행일·증권사·투자의견·목표주가·직전 목표주가·변경률·원문 링크를 표시합니다.
- 최근 3개 달의 월별 리포트 건수를 표시합니다.
- 종합 TOP15 중 최근 리포트에서 직전 목표주가 대비 상향이 명시된 종목의 교집합을 별도 표로 제공합니다.
- 교집합은 `analyst_target_revision_pct`가 실제로 계산되고 0보다 큰 종목만 포함합니다. 직전 목표주가가 확인되지 않는 경우 상향으로 간주하지 않습니다.
- 증권사 전망 10점 배점은 기존 산식을 유지하며, 보고서 메타데이터 추가로 가중치를 변경하지 않습니다.
- 한경 컨센서스는 이용자가 직접 검색하도록 외부 링크로 연결합니다. 현재 자동 수집 원장은 한경 데이터가 아니며, 한경 페이지를 크롤링하거나 그 데이터를 저장하지 않습니다.

## 점검
수집 원장에 실제 데이터가 입력되기 전까지 `analyst_consensus`는 미확보 상태이며 점수는 생성되지 않습니다. 자료가 확보되면 GitHub Actions 실행 결과에서 커버리지와 원문 링크를 검증합니다.
