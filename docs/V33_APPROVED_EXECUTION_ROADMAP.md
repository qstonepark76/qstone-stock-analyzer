# v3.3 승인 개발 계획 (2026-11-28)
사용자 승인: 기존 운영 및 구버전 작업은 재개하지 않고, 신규 모델만 개발한다. 기존 원천자료와 기능은 재사용하고 기존 배점(20/20/10/10/10/10/10/10), 선행지수 100점, 복합 60:40을 유지한다. 유료 데이터 구독 또는 배포는 별도 승인 전 금지.

1. 전망: 공개 증권사 원천, DART 및 기업 IR의 명시적 전망을 우선. 기존 자체 전망은 재무 예측의 보완 연구로만 검증하고, 실제 증권사 상향률·컨센서스·서프라이즈로 대체 금지. 과거 스냅샷은 보존하고 새 수집의 실제 확인일을 기록.
2. 업종 선행: KRX 53개 지수의 기존 21거래일 자료 재사용. 공식 업종/시장 매핑 및 총수익률 여부 검증 후 8점 산출; 업종 이익 전망 7점은 동일 정의/회계연도 및 최소 5개사.
3. 가치: PER/PBR 각 5점. 기존 1,378개 비교기업과 정확한 업종/시총/회계 정의를 활용. EV/EBITDA, PSR, NAV, P/FFO 등은 별도 적합성 검증 실험이며 자동 대체 금지.
4. 업종 상대평가: 차입금 및 리스 주석, 동일 회계기간·세율 확인. 금융업 FISIS/DART/IR의 그룹/법인 범위와 공개일 확인. 중복 배점 방지.
5. 재무·성장: 4개 연간 관측값으로 실제 3년 CAGR 검증, 분기 자료는 동일 범위 및 공시시점 기준으로 별도 비교. 기존 2구간 CAGR과 혼합하지 않는다.
6. 백테스트: 실제 추천 이력은 기존 모델 비교용. 신규 3~5년 point-in-time 검증 목표, 5/20/60 거래일, TOP5/10/15, 60:40 기본 및 70:30/50:50 실험, 비용·MDD·성공률·시장대비 성과. 데이터 없으면 미산출. 학습/검증 분리, 생존편향/상장폐지/수정주가 점검.
7. UI: 기존 라이트그린/밝기 전환/전략·섹터 TOP5·종목 상세·성과 검증 기능 재사용. 신규 후보 화면만 변경하고 데이터 결측과 공식 순위 구분.

목표는 종합·선행 각 95% 이상, 재무·성장 98% 이상(도전 목표), 개별 공식 점수는 모든 입력 충족시에만 제공. 무료 자료 제약은 공개한다. 2026-11-24 동결 회귀 기준 종합 71.40%, 선행 48.78%, 완전 종목 0. 실제 검증 전 병합·배포 금지.

이번 작업: 이전 리포트 원장들의 최초 확인일과 충돌 여부를 재정리하고, 2022년 추가 과거 스트레스 테스트를 실시한다. 2022년은 과거 2024 선택/2025 검증에 더한 추가 시기일 뿐 완전히 독립된 최종 테스트가 아니다. 보험회사는 IFRS17 전환 전 2022년과 현재의 정의가 다르므로 이번 테스트에서 제외. 2026년 11월 24일 점수는 소급 변경하지 않는다.
