# 네이버 증권 투자 전망 직접 활용
사용자 승인대로 네이버 증권의 제공 투자의견·목표가·추정실적을 별도 교차검증 없이 우선 적용하고 KIS를 결측 보완으로 사용한다. 기존 네이버 리포트 6,530건 아카이브 재활용. 종목코드, 회계기간, 날짜, 값의 유무만 처리한다. 동일 증권사 과거 목표가와 현재 목표가로 변경률 산출, KRX 종가와 목표가로 상승여력 계산. KRX ISIN/단축코드 매핑 오류 수정. 기존 직접 전망 결과에서 목표가 상승여력 0건은 가격 연결 오류 가능성이 높았음. 새 계산 결과 확인 전 충족률 상향 금지. 자체 추정실적과 과거 전망 변경률은 별도 검증/이력 필요. 기존 동결 점수 및 배포 변경 없음.
