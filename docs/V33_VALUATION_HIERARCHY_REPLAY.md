# 외부 PER/PBR 제공값과 업종 비교 완화 결합
기존 네이버 제공값 290 대상 및 177 비교기업 아카이브를 재사용. 전수 교차검증 없음. 동일 출처 표시 기준과 조회일 일치, 양수 배수, 최소 5개, 동일 금융모델 유지. 일반기업 세부 업종 부족시 동일 KSIC 두자리 상위 업종. 금융업은 알려진 동일 금융모델 비교 후보로만 산출하며 연결 범위 차이 주의. 기존 12개 대분류 섹터까지 확대할 때의 수치는 진단용(공식 적용 아님). 과거 동결 종합점수에 소급 혼합 금지. 95% 목표를 실제 점수 산출률과 비교. 부족한 비교기업 및 PER 결측을 별도 표시.
