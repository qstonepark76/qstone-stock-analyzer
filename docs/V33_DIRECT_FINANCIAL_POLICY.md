# 재무 건전성 및 수익성 제공값 직접 활용
사용자 승인에 따라 네이버 증권, KRX, 한국투자증권 제공 수치를 재계산/교차검증 없이 우선 활용. 기존 20점(ROE5, ROA3, 영업이익률4, 재무안정성4, 현금창출4) 유지. 데이터 없는 경우 재무제표 표준 산식 보완. 회계연도/실적·추정 구분/출처/조회일/연결·별도 기준 보존, 수치 없는 경우 0으로 대체 금지. 금융업 안정성 및 현금 항목은 일반기업 부채비율·현금흐름으로 대체하지 않고 간소화 상대평가와 중복되지 않는 별도 정의 필요. 이번 첫 실행은 네이버 제공값 확보와 기존 결측 보완 가능성 산정; KRX/KIS 보완, 금융업 세부지표 선택 및 점수 통합은 별도 작업. 과거 동결 데이터 소급 수정 또는 운영 배포 금지.
