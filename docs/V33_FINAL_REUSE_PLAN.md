# v3.3 신규 모델 단일 개발 방침
기존 운영 중단; 기존 소스, 데이터, 추천 이력 보존. 신규 후보 브랜치에서만 개발하고 데이터·수익률 검증 전 병합하지 않는다.

| 단계 | 재사용 및 진행 | 통과 조건 |
|---|---|---|
| 1 | 기존 KRX/KIS 이력, DART 원천 300종목, 연간 성장 추가 자료, 확대 peer 원천, 증권사 원장, 기존 자체 전망 후보 및 지표 검증 산출물 인벤토리/재입력 | 날짜·종목·공시번호·업종·정의 검증, 원천만 신규 배점에 입력 |
| 2 | 기존 KIS 수급 및 수정주가 수집 모듈 재사용, 실제 5/20/60일 확보율 확인, stage 1과 통합 | 중복/누락/시점/가격조정 검증 |
| 3 | 금융업 특화 원천과 가치 대체 지표, 과거 공시·전망 검증자료 재사용, 부족분만 보완 | 중복 가중치 제거, 자체 전망과 실제 컨센서스 구분, 결측 공개 |
| 4 | 신규 100점 종합·100점 선행·60:40 복합 평가, 기존 UI/섹터 TOP5/종목 상세/성과 기록·검증 로직 재사용 | 신규 버전 및 구버전 이력 분리, 데이터 충족 및 회귀 검증 |
| 5 | 과거 검증 당시 추천 이력 및 KRX 가격 이력은 기존 모델 비교 기준으로만 활용; 신규 모델 point-in-time 재생성 | 5/20/60일 실제 수익률, 비교 대상, 거래비용, 데이터 누락 공개 |
| 6 | 신규 모델 배포 검토 | 기존 데이터 충족 목표(각 영역 95%+, 공식 개별 점수 100% 충족), 수익률 검증, 사용자 승인 |

1단계는 실제 증거 artifact를 내려받고, 재무와 peer 원천은 신규 배점으로 재계산한다. CAGR 기존 3개 연간 관측/2개 연간 간격을 그대로 유지하며 실제 3년 CAGR과 혼동하지 않는다. 기존 점수/등급 및 자체 전망값은 외부 컨센서스나 실측 선행신호로 직접 대체하지 않는다. 확대 peer는 추천 대상에 포함하지 않는다. 재사용할 수 없는 항목은 원인과 필요한 추가 데이터로 기록한다.
