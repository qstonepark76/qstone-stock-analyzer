# 추정실적 공식평가 반영 승인 (2026-11-28)
기존 100점/100점/60:40 및 각 지표 배점 유지. 검증된 추정실적을 공식평가 입력으로 허용한다. 출처 우선순위: 복수 증권사(1.00), 개별 증권사(.90), 기업 전망(.85), 자체 모델(.80). 중립점수 기준으로 가감: 0.5 + 신뢰계수 × (원점수 비율 - 0.5). 계수 및 30일 영업이익 변경률의 구간은 사용자 승인한 초기안이며, 실제 예측 검증 후 재조정한다. 데이터 없음은 중립점수로 채우지 않는다.
- 종합평가 예상 영업이익 성장률/이익 전망 변경률 각 2점.
- 선행지수 영업이익 30일 변경률 10, 상향 증권사 비율 8, 업종 전망 7, 전망-주가 괴리 6, 어닝 서프라이즈 6. 기존 목표가 지표는 기존 규칙 유지.
- 상향 증권사 비율은 실제 독립 증권사만. 30일 지표는 실제 30일 전 관측을 요구하며 분기 전망으로 대체하지 않는다. 업종 전망은 동일 출처 유형 및 비교 가능한 기업 최소 5개사. 서프라이즈는 발표 전 전망과 동일 회계기간 실제 실적.
- 자체 모델은 검증자료, 버전, 별도 표본 검증을 요구. 새 입력의 검증 플래그는 원천 검증 과정에서만 생성해야 하며, 코드의 플래그 확인이 외부 독립 검증을 대신하지 않는다. 기존 동결 회귀 스냅샷은 변경하지 않는다. 이전 관측과 새 정책 후보가 중복되면 기존 검증 관측 우선, 검증된 복수 증권사 자료만 대체한다.
