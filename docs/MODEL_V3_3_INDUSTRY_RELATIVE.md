# Q Stone Park v3.3 후보 평가모델 — 업종 내 상대평가

## 1. 목적 및 적용 범위

- 이 문서는 v3.2-beta의 기존 7개 항목 평가모델을 보존하면서, 신규 8개 항목 모델을 별도 검토하기 위한 설계 기준이다.
- 신규 모델은 `v3-3-industry-relative-model` 브랜치에서만 개발·검증한다.
- v3.2-beta 및 공개 운영 사이트의 점수·TOP15·배점은 이 설계만으로 변경하지 않는다.
- 신규 모델의 배점은 총 100점이며 기존 모델의 배점과 혼용하지 않는다.

## 2. 신규 100점 배점

| 항목 | 배점 |
|---|---:|
| 재무 건전성 및 수익성 | 20 |
| 기업 성장성 | 15 |
| 주가 모멘텀 | 10 |
| 외국인 수급 | 10 |
| 기관 수급 | 10 |
| 기업가치(PER/PBR) | 15 |
| 증권사 전망 | 10 |
| 업종 내 상대평가 | 10 |
| **합계** | **100** |

등급 경계는 현행 기준을 유지한다: S 90점 이상, A 80~89.9점, B 70~79.9점, C 60~69.9점, D 60점 미만. 데이터 부족 및 전략 제외는 등급과 별도 상태로 표시한다.

## 3. 업종 내 상대평가 10점의 설계

동일 업종 peer group 안에서 비교하며, 단순히 기존 7개 점수를 다시 백분위화해 추가하지 않는다. 이는 기존 재무·성장·모멘텀·가치 점수를 이중 반영하기 때문이다.

업종 상대평가 10점은 기존 점수 산식에 직접 사용하지 않은 운영 효율·현금창출·재무구조 지표로 구성한다.

| 독립 지표 | 배점 | 산식 방향 |
|---|---:|---|
| 영업이익률 | 2 | 높을수록 우수 |
| 투하자본수익률(ROIC) | 2 | 높을수록 우수 |
| 자산회전율 | 2 | 높을수록 우수 |
| 순차입금/EBITDA | 2 | 낮을수록 우수; 순현금은 우대 |
| 영업현금흐름/영업이익(현금전환율) | 2 | 높을수록 우수 |
| **합계** | **10** | |

각 지표는 동일 업종 peer group의 백분위 점수로 환산한다. peer group은 신뢰 가능한 업종 코드가 일치하는 국내 상장 보통주로 구성한다. 업종 내 유효 비교기업이 5개 미만이면 상대점수를 산출하지 않고 '비교대상 부족'으로 처리한다.

### 데이터 충족 규칙

- 각 지표는 실제 원천 데이터가 확인될 때만 점수에 반영한다.
- 결측값을 0점, 업종 평균 또는 임의 추정치로 대체하지 않는다.
- 업종 상대평가 10점의 충족률이 100%가 아니면 신규 모델의 공식 종합점수/등급을 부여하지 않고 잠정점수와 결측 사유만 제공한다.
- 업종 분류 신뢰도가 낮거나 peer group을 만들 수 없는 종목은 '업종 비교 불가'로 표시한다.
- 금융업 등 EBITDA 또는 순차입금/EBITDA가 경제적으로 부적절한 업종은 해당 지표를 억지로 적용하지 않는다. 업종별 대체 지표를 사전에 정의하고 테스트하기 전까지는 해당 항목을 결측 처리한다.

## 4. 중복 계산 방지 원칙

기존 7개 항목과 신규 업종 상대평가의 지표를 분리한다.

- 재무 건전성 및 수익성(20): 기존 ROE 및 재무 건전성 지표
- 기업 성장성(15): 매출 및 영업이익 성장률
- 주가 모멘텀(10): 5/20/60거래일 가격 모멘텀, 변동성 및 유동성
- 수급(각 10): 외국인 및 기관 순매수
- 기업가치(15): PER/PBR
- 증권사 전망(10): 검증된 목표주가·투자의견·전망 변경
- 업종 내 상대평가(10): 위 5개 독립 운영 효율·현금흐름 지표만 사용

동일 원천 필드가 둘 이상의 평가 항목에 들어가는지 자동 검사하는 테스트를 둔다. 불가피하게 같은 원천 필드를 공유하는 경우에는 신규 업종 상대평가에 중복 가중치를 주지 않도록 산식 변경 전 검토를 필수화한다.

## 5. 종합점수 및 등급 처리

- 가중합은 확정된 8개 항목 배점으로 계산한다.
- 8개 항목 모두 데이터 충족률이 100%일 때만 공식 종합점수와 S/A/B/C/D 등급을 부여한다.
- 일부 항목이 결측이면 잠정점수·충족률·결측 사유를 별도로 제공하되 공식 TOP15에는 포함하지 않는다.
- D등급(60점 미만)과 '데이터 부족', '업종 비교 불가', '전략 제외'는 서로 다른 상태로 유지한다.

## 6. 검증 범위 및 기존 모델 성과 비교에 대한 결정

기존 모델과의 과거 수익률 대결을 신규 모델 도입의 필수 조건으로 두지 않는다. 이번 변경의 목적은 기존 모델의 우열을 판정하는 것이 아니라, 업종 상대평가가 포함된 별도 모델을 설계하는 것이다.

신규 모델 자체에 대해서는 다음을 필수 검증한다.

1. 배점 합계 100점 및 항목별 가중치 테스트
2. peer group 구성 및 최소 비교기업 수 테스트
3. 결측 데이터가 점수·등급·TOP15에 섞이지 않는지 테스트
4. 중복 원천 필드 및 방향성(높을수록/낮을수록 우수) 테스트
5. 업종별 표본 편향 및 이상치 처리 테스트
6. 신규 모델의 점수·등급·TOP15 산출이 재현 가능한지 테스트

운영 전환 여부는 위 검증 통과와 데이터 충족률 확인으로 결정한다. 기존 모델과의 TOP15/성과 비교는 사용자가 별도로 요청하지 않는 한 진행하지 않는다.

## 7. 구현 상태

현재 v3.3 후보 브랜치에서 계산 엔진과 단위 테스트를 분리 구현하는 단계다. 실제 DART 계정 매핑 및 데이터 연결 전에는 공식 점수나 TOP15를 산출하지 않는다. 상세 진행 현황은 아래 8절을 참조한다.

## 9. 기존 사이트 업그레이드 배포 방침 (최신 사용자 요청)

- 신규 사이트/저장소를 만들지 않는다. 최종 배포 주소는 기존 `https://qstonepark76.github.io/qstone-stock-analyzer/`를 유지한다.
- 검증 기간에는 v3.3 후보 브랜치를 유지하고 기존 v3.2-beta 운영 사이트는 변경하지 않는다.
- ROIC 및 순차입금/EBITDA 원천계정 검증, 실제 데이터 충족률 및 업종별 peer 검증, 신규 화면 연결, 통합 테스트가 완료된 후 기존 운영 사이트를 v3.3으로 업그레이드한다.
- 운영 전환 직전 당시 v3.2 운영 커밋을 백업하고 데이터/추천 이력을 보존한다. 모델 버전별 성과 기록은 혼합하지 않는다.
- 기존 v3.2 점수 또는 등급을 v3.3 결과인 것처럼 표시하지 않는다. 공식 추천 데이터가 부족하면 그 상태를 명시한다.
- 기존 배포 경로와 자동 수집 설정을 활용하되, 전환 전에 workflow 및 실제 배포 결과를 검증한다.
- 이전 독립 사이트 배포 방침은 폐기한다. 기존 모델 대비 성과 비교는 필수 단계가 아니다.


## 10. 금융업 특화 상대평가 (사용자 승인)

전체 8개 항목 및 100점 배점은 유지한다. 일반 기업 5개 지표 대신 금융업 세부 모델의 5개 지표(각 2점)를 사용한다.

| 모델 | 높을수록 우수 | 낮을수록 우수 |
|---|---|---|
| 은행 중심 금융지주 | NIM, CET1 | NPL, 대손비용률, CIR |
| 생명보험 | K-ICS, 신계약 CSM 마진율, 보험서비스손익률, 운용자산이익률 | 부실자산비율 |
| 손해보험 | K-ICS, 신계약 CSM 마진율, 운용자산이익률 | 합산비율, 부실자산비율 |
| 증권 | NCR, 유동성비율 | 감독기준 레버리지비율, 우발채무/자기자본, CIR |
| 카드·캐피탈 | 조정자기자본비율, 유동성비율 | 연체율, NPL, 대손비용률 |

- 확인된 상장사 ticker 매핑을 우선 사용한다. 미분류 금융지주·리츠·재보험사 등은 별도 확인 전 점수를 부여하지 않는다.
- 같은 금융업 모델, 연간 결산기간, 지표 정의, 단위, 연결 범위 및 산식 기준이 일치하는 실제 관측치만 비교한다. 은행 중심 금융지주는 연결 그룹 지표만 인정하며 자회사 지표를 대용하지 않는다.
- 유효 비교대상 최소 5개(대상 포함), 모든 지표 충족 시 공식 10점. 표본 부족으로 일부 생명보험·카드 등은 공식 점수 미산출이 가능하다. 검증된 비상장사는 아래 11절에 따라 비교군으로만 허용한다.
- 금융 지표 입력은 `data/financial_industry_observations.json`의 schema_version=1, issuers[ticker].model 및 metrics[metric] 구조를 사용한다. 각 관측치는 value, period(YYYY-MM), unit=percent, verified=true, source, source_ref, definition_id, scope, basis를 포함해야 한다. 검증되지 않은 자료를 이 파일에 넣지 않는다.
- FISIS, OpenDART, 금융투자협회, 생명보험협회, 손해보험협회, 기업 IR 자료를 원천 후보로 한다. 실제 FISIS 인증키 보유 여부, 금융회사 코드, 통계표/계정코드, 지표 정의, 원천값 대조는 아직 검증되지 않았다. API 자동수집은 아직 구현되지 않았다.
- 감독기준 미달 위험 경고는 시행 시점, 업종, 적용 감독규정 및 경과조치가 확인된 후 구현한다. 상대점수와 절대 건전성 경고는 구분한다.
- 금융업 5개 모델 정의, 후보 수집기 경로 연결, 합성 데이터 테스트를 추가했다. 실제 공시 원천 검증, 금융업별 표본 확보, 데이터 수집 자동화, 실제 감독기준 경고 및 화면 표시는 남아 있다.


## 11. 추가 검증 및 비교군 확대

- FISIS 인증키 확인 job(run 45616782909) 실제 결과: `FISIS_AUTH_KEY` 이름의 repository secret 미등록. 소유자가 https://fisis.fss.or.kr/ 의 Open API 인증키 신청 후 GitHub Actions repository secret에 등록해야 한다. 기존 DART 키와 별도다. 인증키를 코드·공개 파일·대화에 기록하지 않는다.
- 금융업 관측치 파일에 `peer_only` 배열을 추가할 수 있다. 동일 금융업 모델, 공시 기준, 기간, 지표 정의 및 범위가 일치하는 독립 비상장사만 비교군에 넣는다. 각 기록에는 listed=false, verified_identity=true, independent_peer=true, entity_id, consolidation_id, identity_source가 필요하다. 상장사와 연결 그룹 중복 및 비상장사 중복을 제외한다. 이 자료는 추천 종목 목록에 들어가지 않는다. 실제 비상장 공시 자료 확보 및 카드·캐피탈 세부 사업모델 일치 여부 검증은 미완료다.
- 삼성전자 2025 연결 공시의 네 차입금 행(단기차입금, 유동성장기부채, 사채, 장기차입금)을 회사·연도·연결 범위에 한정해 매핑했다. 근거: https://www.samsung.com/sec/ir/reports-disclosures/public-disclosure/3755/ . 공시상 유동성장기부채/장기차입금에 포함된 리스부채를 중복 합산하지 않는다. 리스부채 포함 범위의 기업간 비교가능성 및 D&A 주석 계정은 별도 검토 대상이다. 실제 DART 원천응답과 대조 전 검증 완료로 보지 않는다.
- 실제 DART 15개사 audit workflow(run 45616338797)는 공개 재무제표 및 산출값을 artifact에만 저장하고 운영 데이터·사이트를 수정하지 않는다. 결과 확인 전 300개 확대나 배포를 진행하지 않는다.
