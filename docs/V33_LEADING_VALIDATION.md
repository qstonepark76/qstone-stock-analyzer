# v3.3 최종 평가·선행지수 데이터 검증
기존 운영 및 이전 개발 브랜치 변경 금지. 원천 자료 검증 전 공식 추천과 배포 금지.

1. KIS 조회: 기존 고정 300개 2026-11-24 기준, 5/20/60 실제 거래일, 거래량 KRX 일별 대조, 수정주가 조회 및 KRX 종가 대조. 조회 전용, 주문 API 미사용. 누락일은 보간 금지.
2. 재무: 기존 고정 300개 원천 artifact와 expanded direct replay 재사용, 동일 ticker·기준일·공시번호·공시시점 확인. 업종 코드/우선주·중복 발행사 선별 재사용. 기존 금융업 특화 지표와 겹치는 재무 안정성은 별도 지표 확정 전 미산출. 전문 금융업 공개시점, 대체 가치 지표는 추가 검증.
3. 전망: 실제 검증 리포트의 필드 가용성 조사. 같은 회계연도와 증권사·발행사·수정주가 기준으로 30일 전후 matched vintage 필요. 제목, 과거 실적 또는 자체 모델을 외부 컨센서스로 대용하지 않음. 분기 서프라이즈는 실제 공시 전 컨센서스가 있어야 함.
4. 백테스트: `scripts/leading_backtest.py`에 모델 버전 일치 및 point_in_time_verified=true인 불변 후보 snapshot과 수정주가 OHLC 및 동일 시장 벤치마크 패널 입력. 다음 거래일 시가 진입, 신호일 이후 5/20/60 거래일 종가 청산. 동일 비중, 거래비용 왕복 30bp 초기 가정(변경 가능), 배당 미포함 가격 수익률. 평균/초과/승률/최악 cohort MDD 산출. 누락·상장폐지 종목 포함 cohort는 통째로 미검증 처리, 누락 건수 공개. 연속 운용 포트폴리오 MDD와 다름. 동일 날짜·동일 N 후보 비교 및 생존편향/훈련-검증 기간 분리 검증이 추가 필요.
5. 실측 기준: 3~5년 당시 공개 원천, 당시 시총 순위와 상폐 종목, 조정 가격 및 벤치마크 확보 전 실증 결과를 주장하지 않음. 신규 모델 당시 스냅샷이 없는 과거를 현재 점수로 소급하지 않음.
