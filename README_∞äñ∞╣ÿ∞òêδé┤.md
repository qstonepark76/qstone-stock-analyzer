# Q Stone Park Stock Analyzer v3.0-beta

## 포함 파일
- `index.html`: 5개 전략 TOP10 대시보드
- `scripts/collect.py`: KRX 시세 + OpenDART 캐시형 재무 수집 및 점수 산출
- `data/`: 자동 생성 데이터 저장 위치
- `.github/workflows/daily.yml`: 평일 자동 수집 및 GitHub Pages 배포

## 기존 v2.1을 보존하며 테스트하는 방법
1. GitHub 저장소에서 새 브랜치 `v3-beta`를 만듭니다.
2. 압축을 푼 뒤 `QStonePark_v3` 폴더 안의 파일을 저장소의 같은 경로에 업로드합니다. 기존 파일은 `v3-beta` 브랜치에서만 교체됩니다. `data/` 폴더는 비어 있어 업로드하지 않아도 됩니다.
3. 기존 GitHub Secrets `KRX_AUTH_KEY`, `DART_AUTH_KEY`를 그대로 사용합니다(값을 파일에 입력하지 마세요).
4. Actions에서 `Q Stone Park v3.0 Beta Validation`을 선택해 `Run workflow`를 누릅니다. 실행 대상 브랜치는 `v3-beta`로 선택합니다. 완료 후 로그, `data/latest.json`, Artifacts의 `qstone-v3-beta-data`를 확인합니다.
5. 이 테스트 워크플로는 GitHub Pages에 배포하지 않으므로 기존 운영 사이트에 영향을 주지 않습니다. 검증이 끝난 뒤에만 main 반영 및 Pages 배포를 별도로 진행합니다. 검증 전 기존 v2.1 파일은 덮어쓰지 마세요.

## 데이터/평가 원칙
- 고정 배점: 재무 건전성·수익성 20, 성장성 20, 모멘텀 15, 외국인 수급 15, 기관 수급 10, PER/PBR 10, 증권사 전망 10.
- 외국인·기관 수급, PER/PBR, 증권사 전망은 아직 공급자 미연결이며 절대 추정하지 않습니다.
- 공식 종합 TOP10은 7개 영역 전체 커버리지 100%인 경우만 표시합니다. 따라서 초기에는 공식 TOP10이 비어 있을 수 있습니다.
- 재무 TOP10/성장 TOP10/모멘텀 TOP10은 확보된 연결 데이터에 한정한 잠정 참고 목록입니다. 저평가 TOP10은 밸류에이션 공급자 연결 전까지 비어 있습니다.
- 현재 DART 수집은 거래대금 상위 120개를 대상으로 캐시를 활용하는 점진적 수집입니다. 전체 상장사 5개년 연간·3개년 분기 재무 데이터 완성판은 아직 아닙니다.
- 추천일 종가 스냅샷은 저장하지만 1주·1개월·3개월 수익률 및 KOSPI 초과수익률 자동 산출은 다음 단계 구현 항목입니다.

## 주의
이 베타는 배점/화면/데이터 구조의 검증판입니다. 아직 모든 평가 데이터가 연결되지 않았으므로 투자 추천 성과가 검증된 시스템이 아닙니다.
